UX4G ARCHITECTURE CONTRACT

Indian Government UX4G Design System Standard

UX4G is India's government-grade design system developed by MeitY / NeGD / Digital India. It uses standard semantic HTML5 elements with verified ux4g-* CSS classes and atomic design tokens. It requires no React dependency and is designed for fast, accessible, WCAG 2.1 AA and GIGW 3.0 compliant government portals.

1. ACCESSIBILITY COMPONENT

UX4G Standard Topbar & Accessibility Bar

Mandatory for all Government of India portals. Includes National flag, Skip to content, text resizing (A-, A, A+), high contrast, dark mode, and bilingual selection.
